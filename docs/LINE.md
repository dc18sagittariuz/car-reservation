# ติดตั้งบอท LINE แจ้งงานขับรถ

บอทจะทำ 3 อย่าง:
1. **ส่งสรุปงานพรุ่งนี้** เข้ากลุ่มพนักงานขับรถทุกวัน (ค่าเริ่มต้น 17:00 น.)
2. **แจ้งทันที** เมื่องานของวันนี้หรือพรุ่งนี้มีงานใหม่ เปลี่ยนคนขับ หรือถูกยกเลิก
3. **แจ้งผู้ดูแล** เมื่อผู้จองยกเลิกการจองที่อนุมัติแล้ว (และคำขอใหม่ ถ้าเปิดไว้)

ในกลุ่ม พนักงานขับรถพิมพ์ `/งานวันนี้` หรือ `/งานพรุ่งนี้` เพื่อดูงานได้ตลอดเวลา

ใช้เวลาตั้งค่าประมาณ 20–30 นาที ทำตามลำดับ

---

## ขั้นที่ 1 · สร้าง LINE Official Account และเปิด Messaging API
1. เข้า https://manager.line.biz แล้วล็อกอินด้วยบัญชี LINE
2. กด **สร้างบัญชี LINE OA** ตั้งชื่อ เช่น "แจ้งงานรถ (ชื่อหน่วยงาน)"
3. ในบัญชีที่สร้าง ไปที่ **ตั้งค่า (Settings)** → **Messaging API** → **เปิดใช้ Messaging API** → เลือกหรือสร้าง Provider → ตกลง
4. ไปที่ **ตั้งค่าการตอบกลับ (Response settings)**
   - **Webhook**: เปิด
   - **ข้อความตอบกลับอัตโนมัติ (Auto-reply)**: ปิด
   - **ข้อความทักทาย (Greeting)**: ปิดได้ (บอทมีข้อความต้อนรับของตัวเอง)
5. ไปที่ **ตั้งค่าบัญชี (Account settings)** → เปิด **อนุญาตให้บอทเข้าร่วมแชทกลุ่ม**

## ขั้นที่ 2 · เอาคีย์จาก LINE Developers
1. เข้า https://developers.line.biz/console → เลือก Provider → เลือก Channel ของบอท
2. แท็บ **Basic settings** → คัดลอก **Channel secret**
3. แท็บ **Messaging API** → เลื่อนลงล่างสุด → **Channel access token (long-lived)** → กด **Issue** → คัดลอก

> ⚠️ สองค่านี้เป็นความลับ ห้ามใส่ใน GitHub หรือส่งในแชท ใส่ใน Supabase เท่านั้น

## ขั้นที่ 3 · ตั้ง Secrets ใน Supabase
Supabase Dashboard → **Edge Functions** → **Secrets** → เพิ่ม 2 ตัว แล้วกด Save

| Name | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | Channel access token จากขั้นที่ 2 |
| `LINE_CHANNEL_SECRET` | Channel secret จากขั้นที่ 2 |

## ขั้นที่ 4 · สร้าง Edge Function `line-bot`
1. Supabase Dashboard → **Edge Functions** → **Deploy a new function** → **Via Editor**
2. ตั้งชื่อฟังก์ชันว่า `line-bot` (ต้องตรงตัวนี้)
3. ลบโค้ดตัวอย่างทั้งหมด แล้ววางโค้ดจากไฟล์ `supabase/functions/line-bot/index.ts`
4. กด **Deploy function**
5. เปิดฟังก์ชัน `line-bot` → **Details / Settings** → **ปิด "Verify JWT"** (Enforce JWT verification) → Save
   ต้องปิด เพราะ LINE และฐานข้อมูลเรียกฟังก์ชันนี้โดยไม่มี JWT ฟังก์ชันตรวจลายเซ็นของ LINE เองอยู่แล้ว

## ขั้นที่ 5 · ติดตั้งส่วน LINE ในฐานข้อมูล
Supabase → **SQL Editor** → New query → วางไฟล์ `supabase/line.sql` ทั้งหมด → **Run**

ไฟล์นี้เปิดส่วนเสริม `pg_net` และ `pg_cron` ให้เอง และตั้งเวลาส่งสรุปงานทุกวัน

## ขั้นที่ 6 · ตั้ง Webhook URL ใน LINE
LINE Developers → Channel ของบอท → แท็บ **Messaging API** → **Webhook settings**
- **Webhook URL**: `https://xoiisukhkvzinumzmvqf.supabase.co/functions/v1/line-bot`
- กด **Verify** → ต้องขึ้น **Success**
- เปิด **Use webhook**

## ขั้นที่ 7 · เชื่อมกลุ่มพนักงานขับรถ
1. เว็บจองรถ → เมนู **แจ้งงานกลุ่ม LINE** → กด **สร้างรหัสเชื่อมต่อ**
2. ในแอป LINE เพิ่มบอทเป็นเพื่อน (ค้นหาด้วย Basic ID ที่ขึ้นในหน้าเว็บ หรือ QR ใน LINE OA Manager)
3. เชิญบอทเข้ากลุ่มพนักงานขับรถ แล้วพิมพ์ในกลุ่ม: `/ตั้งกลุ่มคนขับ 123456` (ใช้รหัสจากหน้าเว็บ)
4. รับแจ้งเตือนผู้ดูแลแบบส่วนตัว: สร้างรหัสใหม่ แล้วพิมพ์ในแชทส่วนตัวกับบอท: `/ตั้งผู้ดูแล 123456`
5. หน้าเว็บจะขึ้น ✅ เชื่อมแล้ว → กด **ส่งข้อความทดสอบ**

## เรื่องโควตาข้อความ
- LINE OA แพ็กเกจฟรีในไทยส่งได้ประมาณ **300 ข้อความ/เดือน** (ตรวจตัวเลขล่าสุดใน LINE OA Manager → ค่าใช้จ่าย)
- ส่งเข้ากลุ่ม 1 ครั้ง **นับตามจำนวนสมาชิกในกลุ่ม** เช่น กลุ่ม 6 คน = 6 ข้อความ
- ข้อความที่บอท **ตอบกลับคำสั่ง** (`/งานวันนี้`, `/งานพรุ่งนี้`) **ไม่นับโควตา**
- ระบบออกแบบให้ประหยัด: แจ้งทันทีเฉพาะงานวันนี้/พรุ่งนี้ที่ส่งสรุปไปแล้ว งานล่วงหน้าไกลกว่านั้นจะอยู่ในสรุปประจำวันของวันนั้นเอง
- หน้าเว็บแสดงโควตาที่ใช้ไปของเดือนนี้ ถ้าใกล้เต็ม ให้ปิด "แจ้งทันที" แล้วให้คนขับใช้คำสั่ง `/งานพรุ่งนี้` แทน

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| Verify webhook ไม่ผ่าน | ตรวจว่าปิด Verify JWT แล้ว และตั้ง `LINE_CHANNEL_SECRET` ถูกต้อง |
| พิมพ์คำสั่งแล้วบอทเงียบ | ตรวจว่าเปิด Use webhook และปิด Auto-reply ใน LINE OA Manager |
| ประวัติการส่งขึ้น "ส่งไม่สำเร็จ" | ดูข้อความ error ใต้รายการ ส่วนมากเป็น token ผิด หรือโควตาเต็ม ระบบลองส่งซ้ำเองทุก 15 นาที (สูงสุด 3 ครั้ง) |
| ขึ้น "ไม่ได้ส่ง · ยังไม่ได้เชื่อมกลุ่ม" | ยังไม่ได้ทำขั้นที่ 7 |

## ฟีเจอร์เพิ่มเติม

### สรุปงานสัปดาห์หน้า ทุกวันศุกร์
ส่งเข้ากลุ่มคนขับอัตโนมัติทุกวันศุกร์ (ค่าเริ่มต้น 16:00 น.) เปิด/ปิดและเปลี่ยนเวลาได้ที่หน้าเว็บ → แจ้งงานกลุ่ม LINE → การแจ้งเตือนอัตโนมัติ

### ตัวนับโควตาข้อความ
หน้า แจ้งงานกลุ่ม LINE แสดง ข้อความที่ใช้ไป / โควตา, ที่เหลือ, คาดการณ์ถึงสิ้นเดือน และจำนวนครั้งที่ระบบส่ง

### ปฏิทินงานสำหรับพนักงานขับรถ (เปิดในมือถือ ไม่ต้องล็อกอิน)
- ลิงก์อยู่ที่หน้าเว็บ → พนักงานขับรถ (Admin) หรือ แจ้งงานกลุ่ม LINE (Super Admin)
- ถ้าลิงก์หลุดไปถึงคนนอก Super Admin กด **สร้างลิงก์ใหม่** ลิงก์เก่าจะใช้ไม่ได้ทันที

### Rich menu (ปุ่มลัดใต้แชทกับบอท)
1. หน้าเว็บ → แจ้งงานกลุ่ม LINE → กด **ติดตั้งเมนู**
2. พนักงานขับรถเพิ่มบอทเป็นเพื่อน แล้วเปิดแชทส่วนตัวกับบอท จะเห็นเมนู 6 ปุ่ม: งานวันนี้ · งานพรุ่งนี้ · สัปดาห์นี้ · สัปดาห์หน้า · ปฏิทินงาน · ช่วยเหลือ
3. คนที่กดดูได้ต้องอยู่ในกลุ่มคนขับที่มีบอทอยู่ด้วย (คนนอกกดแล้วจะไม่เห็นข้อมูล)
4. ข้อความที่บอทตอบจากเมนู **ไม่นับโควตา**

> LINE แสดง Rich menu เฉพาะในแชทส่วนตัวกับบอท ไม่แสดงในแชทกลุ่ม ในกลุ่มยังพิมพ์คำสั่ง `/งานวันนี้` `/งานสัปดาห์หน้า` `/ปฏิทิน` ได้ตามปกติ
